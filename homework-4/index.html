Exercise 1

Welford's Recurrence Formulas

01

Derivation

After k scores x₁, …, xₖ let Mₖ = (1/k) ∑ xᵢ be the mean and Sₖ = ∑ (xᵢ − Mₖ)² the sum of squares, with M₀ = S₀ = 0.

Mean (Knuth)

kMₖ = (k − 1)Mₖ₋₁ + xₖ ⇒ Mₖ = Mₖ₋₁ + (xₖ − Mₖ₋₁) / k

Sum of squares

Same approach: write Sₖ = ∑ xᵢ² − kMₖ² and take the difference of two consecutive steps.

Sₖ − Sₖ₋₁ = xₖ² − kMₖ² + (k − 1)Mₖ₋₁²
= xₖ² − kMₖ² + (kMₖ − xₖ)Mₖ₋₁using (k − 1)Mₖ₋₁ = kMₖ − xₖ
= xₖ(xₖ − Mₖ₋₁) − kMₖ(Mₖ − Mₖ₋₁)
= xₖ(xₖ − Mₖ₋₁) − Mₖ(xₖ − Mₖ₋₁)using k(Mₖ − Mₖ₋₁) = xₖ − Mₖ₋₁
Sₖ = Sₖ₋₁ + (xₖ − Mₖ₋₁)(xₖ − Mₖ)

Variance

Since xₖ − Mₖ = (k − 1)(xₖ − Mₖ₋₁)/k, the step is also Sₖ = Sₖ₋₁ + (k − 1)(xₖ − Mₖ₋₁)²/k. Dividing by k − 1 gives the sample variance sₖ² = Sₖ/(k − 1), for k ≥ 2:

sₖ² = ((k − 2)/(k − 1)) sₖ₋₁² + (xₖ − Mₖ₋₁)² / k
02

Code

function welford(scores) {
  let k = 0, M = 0, S = 0;
  for (const x of scores) {
    const d = x - M;         // xₖ − Mₖ₋₁
    M += d / ++k;            // Mₖ
    S += d * (x - M);        // Sₖ
  }
  return { mean: M, ss: S, variance: S / (k - 1) };
}

Conclusions

  • The average of the sampling means is close to μ = 3: E[x̄] = μ, the sampling mean is an unbiased estimator of μ.
  • The average of the sampling variances is close to σ² = 2.1: dividing by n − 1 makes E[s²] = σ². Dividing by n would give (n − 1)σ²/n, too small.
  • Each single hacker can be far from μ and σ²; only the average over many hackers settles on them.

Why it matters in inference

μ and σ² are usually unknown and only one sample is observed. Because x̄ and s² are unbiased, they estimate them with no systematic error, and s² also measures how precise x̄ is, through Var(x̄) = σ²/n. Confidence intervals and tests are built on this.
