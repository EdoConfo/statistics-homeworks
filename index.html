Homework 1

Private key → public key on a toy elliptic curve

Scalar multiplication Q = kG on y² = x³ + 7 (mod 17): point addition, double-and-add, a step-by-step SVG animation, and a statistical look at the outputs. Includes coordinate distributions, bit balance, correlation, avalanche, and what separates a one-way function from a hash.

Homework 2

From seed phrase to Ethereum address

The wallet pipeline step by step: BIP-39, BIP-32, BIP-44, secp256k1, Keccak-256 and EIP-55, each classed as generation, derivation, public-key crypto, hashing, checksum or encoding. Also a live demo, Monte Carlo checks of checksum strength, a timeline, and Keccak vs SHA-3.

No build step

Plain HTML, CSS and ES modules served by GitHub Pages. HW1 has no dependencies. HW2 loads pinned builds of the audited noble libraries for the hash and curve primitives. The wallet logic on top of them is written out step by step.

Tested

The math is checked with node --test against known vectors: the assignment's 6G = (5, 8), BIP-39/BIP-32 test vectors, EIP-55 examples and the Hardhat test accounts. HW2 repeats the checks in the browser on every load.

Educational only

Toy curves are trivially breakable, and the code is not constant-time. The wallet demo only uses generated or public test phrases. Never type a real recovery phrase into a website.
