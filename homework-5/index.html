Riemann and Lebesgue Integration

The same area cut in two directions: vertical strips over a partition of the domain, horizontal slabs over a partition of the range. Both computed numerically, compared, and pushed to functions where they stop agreeing.

01

Two ways to cut the area

For a function f ≥ 0 on [a, b].

Riemann: partition the domain

Split [a, b] into N subintervals of width h = (b − a)/N, pick a point ξᵢ in each and add the rectangles:

RN = ∑ᵢ f(ξᵢ) h → ∫ₐᵇ f(x) dx

Here ξᵢ is the midpoint. The limit must be the same for every choice of points, otherwise f is not Riemann-integrable.

Lebesgue: partition the range

Split the values y₀ < y₁ < … < yN and take the preimages Eₖ = f⁻¹([yₖ₋₁, yₖ)), sets of points of the domain with their measure μ(Eₖ):

LN = ∑ₖ yₖ μ(Eₖ) → ∫ f dμ

Regrouping the sum by levels gives the same thing as slabs of height Δy and length μ{f > y}: ∫ f dμ = ∫₀^∞ μ{x : f(x) > t} dt.

Riemann: N strips

Lebesgue: N slabs

In the Lebesgue picture each slab is drawn only over the set where f > t, so its area is Δy · μ{f > t}. The set can be several intervals (for |x − 0.5|, two).

02

The numerical methods

Riemann sum

Midpoint rule: N evaluations of f, nothing else.

let s = 0;
for (let i = 0; i < N; i++) s += f(a + (i + 0.5) * h);
return s * h;

Lebesgue sum

Levels tk at the midpoints of N equal steps of the range [min f, max f], and

LN = min f · (b − a) + ∑ₖ Δy · μ{f > tₖ}

The hard part is the measure of the preimage. It is found on a grid of 2 048 cells: a cell entirely above tₖ counts whole, a cell where f crosses tₖ is cut at the crossing, located by bisection to machine precision.

For an unbounded f such as 1/√x the range is cut at a level that grows with N (here 1 + N2/3): the part of the area above it is lost, as the Riemann sum loses the area next to x = 0. The grid assumes f crosses each level at most once inside a cell, true for every function below.

Error against N

Log–log scale. An exact result (error 0) is drawn at the bottom of the chart.

  • Smooth functions (sin x, x², sin x / x): Riemann converges like N⁻², Lebesgue like N−1.5. The Lebesgue error is set by how smooth t ↦ μ{f > t} is, not f: where f′ = 0 (the top of sin x, the bottom of x²) this function has a square-root corner, e.g. μ{x² > t} = 1 − √t.
  • Step functions: Lebesgue is exact for every N, since μ{f > t} is constant between the two values. Riemann is exact only when the jump falls on a partition point; with odd N it sits inside a strip and the error is of order 1/N.
  • |x − 0.5|: μ{f > t} = 1 − 2t is a straight line, so Lebesgue is exact. Riemann is exact on each linear piece and errs only in the strip containing the corner, order N⁻².
  • 1/√x: both are slow, about N−1/2, because the area is concentrated near x = 0, where the values are unbounded.

Computational efficiency

A Riemann sum costs N evaluations. A Lebesgue sum costs the grid (2 049 evaluations) plus about 50 bisection steps for every crossing of every level, so it is tens of times more expensive. On an interval of the real line, where measuring a preimage means finding where f crosses a level, the domain partition is the cheaper one. The range partition pays off when the measure of {f > t} is known or easy to estimate, and when the function is too irregular for strips (section 06).

05

Do they converge to the same value?

Yes, for every function above: the two columns of section 03 agree with the exact integral within 10⁻⁶ for the bounded ones, and their difference keeps shrinking as N grows. This is a theorem: a bounded function that is Riemann-integrable on [a, b] is also Lebesgue-integrable, with the same integral.

1/√x is not Riemann-integrable in the strict sense (it is unbounded on (0, 1]); its improper Riemann integral limε→0 ∫ε¹ x−1/2 dx = 2 exists and equals the Lebesgue integral ∫₀^∞ μ{f > t} dt = 1 + ∫₁^∞ t⁻² dt = 2. Both numerical sums approach 2, slowly.

06

Dirichlet function: the two approaches disagree

f(x) = 1 if x is rational, 0 if irrational, on [0, 1].

Riemann

Every subinterval contains rationals and irrationals, so for every N the upper sum is 1 and the lower sum is 0. Rational points ξᵢ (such as the midpoints) give RN = 1, irrational ones (midpoint + h/(10√2)) give RN = 0. No limit: not Riemann-integrable. (In the table each point is rational or irrational by construction; the code does not test a float.)

Lebesgue

The range has two values. f⁻¹(1) = ℚ ∩ [0, 1] is countable, so it has measure 0: list the rationals r₁, r₂, … and cover rₖ with an interval of length ε/2ᵏ, total length at most ε, for every ε > 0. Then

∫ f dμ = 1 · μ(ℚ ∩ [0, 1]) + 0 · μ(irrationals) = 0

Lebesgue gives a value where Riemann gives none.

A computer cannot tell the two apart: every floating-point number is a fraction m/2ᵏ, hence rational. Evaluated in code, the Dirichlet function is 1 at every point it can be asked about, and any sum of samples returns 1. The value 0 comes from the measure, not from sampling.

07

Thomae's function: they agree again

f(p/q) = 1/q in lowest terms, 0 at irrationals. Discontinuous at every rational, yet both integrals are 0. Rational points are handled as exact fractions (p, q), not as floats.

Riemann sums against N

Upper sum: on each strip, 1/q for the smallest denominator q it contains. Lower sum: 0.

Riemann

Only finitely many points have f ≥ 1/q, each touches at most two strips, and the upper sum goes to 0 (). The lower sum is 0. Riemann-integrable, integral 0: its discontinuities, the rationals, have measure zero.

Lebesgue

For any level t > 0, {f > t} is a finite set of fractions, measure 0. Every slab has length 0 and LN = 0 exactly, for every N.
